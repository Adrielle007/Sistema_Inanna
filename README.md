# Sistema_Inanna
Sistema de Gestão de serviços de beleza e estética


O Inanna é um sistema de Gestão de serviços de beleza e estética, capaz de atender barbearias, salões e clínicas de estética. Objetivo é que diferentes tipos de negócios, relacionados a estética, utilizem a mesma estrutura de banco de dados.

Um cliente entra em contato com o estabelecimento, escolhe um serviço, escolhe um profissional e agenda um horário. O profissional realiza o atendimento e o cliente efetua o pagamento.
