# Sistema_Inanna

Inanna - Sistema de Gestão para Beleza e Estética 

Sistema de gestão desenvolvido para estabelecimentos do segmento de beleza e estética, como barbearias, salões de beleza, clínicas de estética.

O sistema foi pensado para atender diferentes tipos de estabelecimentos utilizando uma estrutura de dados única e organizada, permitindo o gerenciamento de:

-Estabelecimentos;


-Clientes;


-Profissionais;


-Categorias de serviços;


-Serviços;


-Disponibilidade de profissionais; 


-Agendamentos;


-Pagamentos;


-Fidelidade;



A proposta do projeto é apresentar, por meio de um banco de dados relacional, o funcionamento de estabelecimentos que trabalham com serviços de beleza e estética. 

---Problema


Estabelecimentos de beleza e estética precisam administrar diariamente diversas informações relacionadas aos seus clientes, profissionais, serviços, horários e pagamentos.


Quando essas informações não são centralizadas, podem ocorrer problemas como:



-Conflitos de horários;


-Dificuldade para localizar informações de clientes;


-Dificuldade para controlar os serviços oferecidos;


-Falta de organização dos profissionais;


-Dificuldade no acompanhamento dos agendamentos;


-Inconsistências nos registros de pagamento;



O Inanna busca solucionar esse problema por meio da centralização e organização dessas informações em uma estrutura de banco de dados relacional.


--Objetivo 


O objetivo principal do Inanna é desenvolver uma estrutura capaz de desenvolver uma estrutura capaz de representar o funcionamento de diferentes estabelecimentos de beleza e estética.


O sistema deve permitir que um estabelecimento:



1.Cadastre seus serviços;


2.Organize os serviços por categorias;


3.Cadastre seus profisionais;


4.Associe profissionais aos estabelecimentos onde trabalham;


5.Defina quais serviços podem ser realizados pelos profissionais;


6.Cadastre clientes;


7.Registre agendamentos;


8.Registre pagamentos;


9.Acompanhe o histórico dos atendimentos;



Assim o Inanna vai conseguir cumprir com o seu obejetivo.
